# 7-minute demonstration script

Prepare: npm ci, npm run build, npm start; demo mode enabled. Clear demo data in Profile. Use a clean browser tab. Do not show terminals containing secrets or provider settings.

| Time | Screen and talking point |
|---|---|
| 0:00–0:45 | Home: introduce the problem, tagline and Nigerian student research population. Explain this is a Full Stack capstone, not model training. |
| 0:45–1:30 | Resize to mobile: show navigation, hierarchy, focus and responsive cards. Mention documented tokens and wireframes. |
| 1:30–2:15 | Explore Experts: search Ngozi, filter country/field, show draft status and no endorsement. Reset and select Amara. |
| 2:15–3:30 | Amara profile and Ask: explain fictional notes. Submit “How can I explore a career and practise a new skill?” Read excerpts and open [1], source metadata and original note. Explain demo is extractive; live server uses Responses API. |
| 3:30–4:00 | Submit “What is quantum entanglement?” Show exact insufficiency response. Choose a real draft expert and show the same safe boundary. |
| 4:00–4:45 | Save an answer, give helpful feedback, submit a test report. Visit My Questions and Saved Answers. Explain local browser scope. |
| 4:45–5:20 | Sign-in/register interfaces: explain Supabase configuration, verified sessions and live account persistence. Do not claim an account exists in demo mode. |
| 5:20–6:00 | Admin preview: show counts, catalogue status controls, document rights/approval structure and review queue. Explain temporary controls and protected live admin role. |
| 6:00–7:00 | Open architecture, SQL migration, README, wireframes and verification record. Explain retrieval before generation, RLS, private sources, citation checks, deployment plan and remaining live configuration. |

Finish by stating the persistent AI disclosure. Avoid presenting synthetic notes as real publications or attributing any demo sentence to a real expert.
